# Changelog

## v1.0 — 2026-11-20

- Consolidated the development milestones into the first official release designation, v1.0. This normalizes release numbering without changing skill behavior or rewriting Git history.
- Provides an intent-based SKILL.md router with selective reference loading for creation, image edits, prompt revision, model-neutral analysis and failed-generation correction, including negative boundaries for fixed cameras, identity-only references and ordinary follow-ups.
- Uses explicitly named image models without confirmation and inherits an established model until changed. Questions are limited to unresolved consequential choices.
- Includes all seven references covering the core workflow, architectural geometry fidelity, material realism and context-sensitive imperfections, photographic realism, reference deconstruction, visual QA, and project continuity. Preserves both model output contracts, authorized design changes and already approved characteristics during correction.
- Includes 25 positive/negative routing fixtures, dependency-free metadata/path/encoding/fixture checks, 16 deterministic mutation and trace-scoring tests, and an opt-in real Codex CLI reader-trace harness. Static validation and the deterministic tests passed.
- Includes six complete hypothetical usage examples, installation/testing/contribution guidance, an exact directory tree, and push/PR GitHub Actions checks.
- Includes the architectural hero banner, eight-image vertical gallery and compatibility guidance. Claude, Claude Code and Gemini compatibility remains unverified through testing.
- Provides a prepared comparison protocol for v1.0 against a documented baseline prompting approach. No image-generation benchmark has been executed and no image-quality improvement is claimed. Live text-agent evidence is runtime-specific; seeded follow-up context does not test a resumed dialogue. Semantic correctness is not established by output-block checks alone.
- Windows development CLI behavior tests were blocked by execution policy before file reads; they do not establish live routing correctness.
- Licensing remains undecided; no LICENSE or third-party assets were added.

The package is independent, and is not endorsed by OpenAI, Google or any of the cited GitHub projects.
